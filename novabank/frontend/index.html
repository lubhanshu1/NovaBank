Concept: Row Locking (SELECT ... FOR UPDATE) & Deadlock Detection

When two transactions attempt to acquire locks on the same resources in reverse order, a circular wait (deadlock) occurs. MySQL InnoDB automatically detects cycles and aborts one transaction with ERROR 1213 (Deadlock found).

How NovaBank Eliminates Deadlocks in Production:

In sp_transfer_funds, NovaBank orders account IDs deterministically before acquiring locks: IF v_from_id < v_to_id THEN SELECT ... v_from_id FOR UPDATE; SELECT ... v_to_id FOR UPDATE;. Because all concurrent transfers lock resources in strictly ascending numerical order, circular wait conditions become mathematically impossible!
